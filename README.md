# Morada

Landing page cinematográfica para uma imobiliária premium, feita com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

As imagens e o vídeo do hero usam URLs públicas de demonstração. Substitua os links em `src/data.ts` e nos componentes quando os materiais finais estiverem disponíveis.
